# Code of conduct

Alcazar follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, welcome newcomers (legacy
languages have a steep learning curve and few people still teach them), and
keep discussions about code, not people.

Report unacceptable behaviour privately to the maintainers through the
repository's *Security → Report a vulnerability* form (it is private) or by
contacting a maintainer directly. Reports are handled confidentially.
